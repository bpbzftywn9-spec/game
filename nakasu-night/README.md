# 仁義 中洲ナイト

福岡の天神・中洲・博多を舞台に、繁華街の治安を裏から守る3Dアクション（Web版、Three.js）。
ギャング〈福博連合〉と匿名・流動型犯罪グループ〈トクリュウ〉を成敗し、夜の街をきれいにしていく。

- 遊ぶ：`npm run serve` → http://localhost:8123/web/index.html
- 公開（Cloudflare Pages）：`docs/cloudflare-pages.md`
- 開発のルールと経緯：`AGENTS.md`
- App Store版（Unity）の計画：`docs/unity-appstore-plan.md`
