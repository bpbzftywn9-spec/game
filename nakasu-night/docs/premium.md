# 課金（プレミアムアイテム）の仕様

オーナーの指示（2026年11月24日）：課金ポイントは **服装・武器・車・アクセサリー** と、**飲み屋・クラブでの酒代（シャンパンなど）**。価格はオーナーの指示で、最初の案の10倍に決定。まずWeb版でリリースする。

## 基本方針
- 価格は日本円・税込。**ゲーム内通貨（¥）は売らない**。アイテムを直接売る（資金決済法の「前払式支払手段」に当たらないようにするため。「仁義サンシャイン」と同じ考え方）。
- ガチャ（確率で当たるもの）は作らない。何が買えるかは、買う前に全部わかる。
- 服装・武器・車・アクセサリーは **一度買えばずっと使える**（買い切り）。何度でも着替え・乗り換えができる。
- 酒代は **飲むたびに払う**（消費型）。
- 武器は「素手の喧嘩で決着する」という決まりを守り、**拳に着ける装備** にした（バンテージ・グローブ・メリケンサック）。刃物・銃は入れない。
- 購入前に確認画面を出す：商品名・内容・税込価格、年齢の確認（酒は「20歳以上」、それ以外は「18歳以上、または保護者の同意」）。

## 客に奢る（ゲーム内のお金）
- 店の客に近づいて「奢る」：一杯（居酒屋 ¥800／スナック ¥1,500／バー ¥2,000／クラブ ¥3,000）、いい酒（その3倍）。1回の来店で1人1回。
- カウンターの「みんなに一杯奢る」：一杯の値段 × 客の人数 × 0.9。店じゅうで乾杯し、その場の写真がヨルスナに自動で投稿される。
- 奢るとヨルスナ（ゲーム内の写真SNS）のフォロワーが増える。店によって増え方が違う（クラブ1.5倍、バー1.3倍）。課金のお酒にもフォロワーが付く（シャンパン +300、シャンパンタワー・店じゅうにシャンパン +1,500 など）。
- 奢りはゲーム内のお金にした（売人の報奨金などの使い道になる）。課金にしたい場合は変更できる。

## 決済のしくみ
- **「仁義サンシャイン」の決済サーバー（Render・Stripe）を共用する**（オーナー決定）。サーバー側の商品と価格は `server/products-nakasu.js`。ゲームの表示価格は、サーバーから受け取った価格を優先する。
- 流れ：確認画面で「購入する」→ Stripe の決済画面 → 支払いが終わるとゲームに戻る →「つづきから」で受け取り（服装などは自動で装備、お酒はその場で効果）。決済に行く前の位置に戻る。
- 1アカウントの月間購入上限：**100,000円**（オーナー決定）（Render の `NAKASU_MONTHLY_LIMIT_JPY` で変えられる）。仁義サンシャインとは別に数える。
- セーブはサーバーにも保存する。機種変更は「引き継ぎコード」（タイトル画面と、プレミアムショップの「機種変更」）。中洲ナイトのコードは中洲ナイトでだけ使える。
- 購入画面に、特定商取引法に基づく表記・利用規約・プライバシーポリシーへのリンクを出す（サーバーのページ。両方のゲームを対象にした）。
- 動作の種類（`web/index.html` の `Pay`）：
  - **販売中**：サーバーにつながり、販売の準備がすべて済んでいるとき。
  - **テスト決済**：サーバーがテスト決済（`PAYMENT_MODE=mock`）のとき。請求なし。
  - **テスト購入**：手元のパソコン（localhost）で、サーバーなしで開いたとき。請求なし。
  - **準備中**：サーバーにつながらないとき、または販売の準備が済んでいないとき。買えない。

## リリースまでに残っていること
1. `web/index.html` の `NAKASU_API_URL` に、Render のサーバーのURLを入れる。
