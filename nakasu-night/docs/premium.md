# 課金（プレミアムアイテム）の仕様　※価格はすべて仮

オーナーの指示（2026年11月24日）：課金ポイントは **服装・武器・車・アクセサリー** と、**飲み屋・クラブでの酒代（シャンパンなど）**。

## 基本方針
- 価格は日本円・税込。**ゲーム内通貨（¥）は売らない**。アイテムを直接売る（資金決済法の「前払式支払手段」に当たらないようにするため。「仁義サンシャイン」と同じ考え方）。
- ガチャ（確率で当たるもの）は作らない。何が買えるかは、買う前に全部わかる。
- 服装・武器・車・アクセサリーは **一度買えばずっと使える**（買い切り）。何度でも着替え・乗り換えができる。
- 酒代は **飲むたびに払う**（消費型）。
- 武器は「素手の喧嘩で決着する」という決まりを守り、**拳に着ける装備** にした（バンテージ・グローブ・メリケンサック）。刃物・銃は入れない。
- 購入前に確認画面を出す：商品名・内容・税込価格、年齢の確認（酒は「20歳以上」、それ以外は「18歳以上、または保護者の同意」）。

## 決済のしくみ（いまの状態）
- **本番の決済はまだつないでいない。** 決済には、カード情報を扱うサーバー（Stripe など）が必要。
- 動作の種類（`web/index.html` の `Pay`）：
  - **テスト購入**：URLの最後に `?pay=test` を付けたとき、または手元のパソコン（localhost）で開いたとき。確認画面に「テスト購入：実際には請求されません」と出て、お金はかからずにアイテムが手に入る。
  - **準備中**：それ以外（Cloudflare Pages にそのまま公開した場合）。価格の代わりに「準備中」と出て、買えない。
- 購入したアイテムは、いまは端末のセーブデータ（localStorage）にだけ保存される。本番では、サーバー側にも購入の記録を残し、機種変更やデータ消去のあとも戻せるようにする必要がある。

## 本番の決済を始めるまでに必要なこと
1. 決済サーバーを決める：①「仁義サンシャイン」の Render サーバー（Stripe 対応済み）を両方のゲームで使う、または ② Cloudflare Pages Functions で新しく作る。
2. Stripe のアカウントで、商品と価格を登録する（オーナーの操作）。
3. 特定商取引法にもとづく表記、利用規約、プライバシーポリシーのページを作る（「仁義サンシャイン」のものを元にできる）。
4. **BAR YAHMAN のお酒をゲーム内で有料販売することについて、店の了承を取る**（店名と、TAIKIさん・おにょさんのセリフを使った有料アイテムになるため）。
5. App Store 版では Apple のアプリ内課金を使う必要がある。審査ガイドラインで、お酒を過度に勧める表現は認められないので、表現と年齢レーティングを見直す。
