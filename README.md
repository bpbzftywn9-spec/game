# 仁義サンシャイン — JINGI SUNSHINE

> 2027年、日米「歓楽街まるごと姉妹都市協定」により、東京の歓楽街〈紅灯町〉はビルごと南国の〈ガルフストリーム州〉へ移設された。
> ネオン、ワニ、ハリケーン、そして極道。――誰も止めなかった。

> 別作品「仁義 中洲ナイト」（福岡が舞台の3D版）は [`nakasu-night/`](nakasu-night/) にあります。

南国クライム・オープンワールド × 極道ベルトスクロール喧嘩アクションを掛け合わせた、スマホのブラウザで遊べる見下ろし型アクションゲームです。
`index.html` 1ファイルだけで動きます（外部ライブラリ・画像なし）。

## 言語（日本語 / English）
ブラウザの言語設定で自動的に切り替わります（日本語以外の環境では英語）。タイトル画面と一時停止メニューの「🌐」ボタンでも切り替えられます。
翻訳は `index.html` 内の `EN`（日本語の文 → 英語）と `EN_HTML`（画面の固定文言）にまとめてあります。文章を追加したときは `EN` にも英語を足してください（無いものは日本語のまま表示されます）。

## 遊び方
- `index.html` をスマホ/PCのブラウザで開く（GitHub Pages などに置けばそのままURLで遊べます）
- 横持ち推奨（縦持ちでも可）

| 操作 | スマホ | PC |
|---|---|---|
| 移動・運転 | 画面左半分をドラッグ | WASD / 矢印 |
| 殴る（3段コンボ） | 殴 | J / Space |
| 蹴る（重い一撃） | 蹴 | K |
| 回避 | 避 | L |
| 極技（ヒートアクション） | HEAT（ゲージ満タン時） | H |
| 乗る/降りる/買う | 状況ボタン | E |

## 主な要素
- **オープンワールド**：ネオン街、ビーチ、桟橋、ワニの沼地、ゴルフ場。昼夜サイクルあり
- **喧嘩バトル**：コンボ、ダウン追い打ち、回避、敵の予備動作（！）、ボス専用技
- **ヒートアクション**：「極・ワニの餌やり」「極・フラミンゴ乱舞」など場所で変わる極技
- **車**：信号のない南国の車道をAI車が走る。奪って運転、轢くと炎上
- **炎上度（手配度）**：市民・警官に手を出すと★が増え、保安官とパトカーが追ってくる。視界から消えれば下がる
- **配信者の相棒**：派手に暴れるほどフォロワーが増え、SNSのタイムラインが実況する
- **ストーリー全5章**：ワニのラーメン屋店主、ゲートボール暴走族、気象操作で保険を売る「ドン・ハリケーン」
- **サブストーリー4本**：カラオケ（リズムゲーム）、迷子のフラミンゴ、フロリダマン選手権、着ぐるみの逃亡者
- **ワニマート**：回復アイテム購入
- 自動セーブ（localStorage）

## 広告で収益化（Webゲームサイト向け）
広告まわりは `index.html` 内の `Ads` オブジェクトにまとめてあります。CrazyGames・Poki・GameDistribution に対応しています。

| 広告の種類 | 出る場所 |
|---|---|
| リワード広告（見るかどうかはプレイヤーが選ぶ） | ワニマートの「ランダムな武器を1つ」「協賛金 $300」（3分に1回）／ゲームオーバー時の「その場で復活」 |
| インタースティシャル広告（区切りで自動） | ミッションクリア後、病院で目を覚ましたとき（3分以上あける） |

ほかに、プレイ中かどうかの通知（gameplayStart/Stop）、読み込み完了の通知、ミッションクリア時の happytime（CrazyGames）、広告中のゲーム停止と消音も入れてあります。

### アップロード用ファイルの作り方
```
python3 tools/build_portals.py --gd-game-id <GameDistributionのゲームID>
```
`dist/crazygames.zip`・`dist/poki.zip`・`dist/gamedistribution.zip` ができます。各サイトの開発者ページにアップロードしてください。

### ローカルで広告の流れを試す
`index.html?ads=test` で開くと、本物の広告の代わりに数秒のテスト表示が出ます。

## 自分のサイトでカード決済（Stripe）
`server/` は、ゲーム配信・セーブの保存・課金をまとめて行うサーバーです（Node.js 22.13 以上、外部パッケージなし）。

- **プレミアムショップ**：一時停止メニューとワニマートから開けます。商品は武器のみ（ゲーム内通貨は売りません）で、`server/products.js` で設定します
- **決済**：Stripe Checkout（カード、コンビニ払いなど、Stripe で有効にした支払い方法）。Webhook の署名を検証し、同じ注文で二重にアイテムが付与されない作り
- **未成年対策**：購入前の年齢確認のチェック、1アカウントの月間購入上限（初期値 ¥10,000）
- **セーブ**：サーバーにも保存。「機種変更（引き継ぎ）」コードで別の端末に移せます（コードは1回限り）
- **法的ページのひな形**：`server/public/legal/` の特定商取引法に基づく表記・利用規約・プライバシーポリシー（【要記入】を埋めてください）

### 手元で試す（請求なし）
```
cd server
npm start          # http://localhost:8787 をブラウザで開く
npm test           # API の自動テスト
```
`PAYMENT_MODE=mock`（初期値）では、本物の決済の代わりにテスト決済ページが開きます。

### 本番で動かす
**詳しい手順は [DEPLOY.md](DEPLOY.md)**（Render のブループリント `render.yaml` 付き）。販売者情報と Stripe の設定がそろうまで、販売は自動で止まります。

1. Stripe アカウントを作り、事業者情報と特商法ページのURLを登録する
2. `server/.env.example` を参考に環境変数を設定する（`PAYMENT_MODE=stripe`、`NODE_ENV=production`、`STRIPE_SECRET_KEY`、`STRIPE_WEBHOOK_SECRET`、`PUBLIC_URL`）
3. Stripe の Webhook を `https://あなたのドメイン/api/stripe/webhook` に設定する（イベント：`checkout.session.completed`、`checkout.session.async_payment_succeeded`）
4. `Dockerfile` で Render・Fly.io・VPS などにデプロイする。**SQLite のファイル（`/data`）は消えないディスクに置くこと**
5. まず `sk_test_` のテストキーとテストカード（4242 4242 4242 4242）で一通り試してから、本番キーに切り替える
