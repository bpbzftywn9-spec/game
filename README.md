# 仁義サンシャイン — JINGI SUNSHINE

> 2027年、日米「歓楽街まるごと姉妹都市協定」により、東京の歓楽街〈紅灯町〉はビルごと南国の〈ガルフストリーム州〉へ移設された。
> ネオン、ワニ、ハリケーン、そして極道。――誰も止めなかった。

南国クライム・オープンワールド × 極道ベルトスクロール喧嘩アクションを掛け合わせた、スマホのブラウザで遊べる見下ろし型アクションゲームです。
`index.html` 1ファイルだけで動きます（外部ライブラリ・画像なし）。

## 遊び方
- `index.html` をスマホ/PCのブラウザで開く（GitHub Pages などに置けばそのままURLで遊べます）
- 横持ち推奨（縦持ちでも可）

| 操作 | スマホ | PC |
|---|---|---|
| 移動・運転 | 画面左半分をドラッグ | WASD / 矢印 |
| 殴る（3段コンボ） | 殴 | J / Space |
| 蹴る（重い一撃） | 蹴 | K |
| 回避 | 避 | L |
| 極技（ヒートアクション） | HEAT（ゲージ満タン時） | H |
| 乗る/降りる/買う | 状況ボタン | E |

## 主な要素
- **オープンワールド**：ネオン街、ビーチ、桟橋、ワニの沼地、ゴルフ場。昼夜サイクルあり
- **喧嘩バトル**：コンボ、ダウン追い打ち、回避、敵の予備動作（！）、ボス専用技
- **ヒートアクション**：「極・ワニの餌やり」「極・フラミンゴ乱舞」など場所で変わる極技
- **車**：信号のない南国の車道をAI車が走る。奪って運転、轢くと炎上
- **炎上度（手配度）**：市民・警官に手を出すと★が増え、保安官とパトカーが追ってくる。視界から消えれば下がる
- **配信者の相棒**：派手に暴れるほどフォロワーが増え、SNSのタイムラインが実況する
- **ストーリー全5章**：ワニのラーメン屋店主、ゲートボール暴走族、気象操作で保険を売る「ドン・ハリケーン」
- **サブストーリー4本**：カラオケ（リズムゲーム）、迷子のフラミンゴ、フロリダマン選手権、着ぐるみの逃亡者
- **ワニマート**：回復アイテム購入
- 自動セーブ（localStorage）

## 広告で収益化（Webゲームサイト向け）
広告まわりは `index.html` 内の `Ads` オブジェクトにまとめてあります。CrazyGames・Poki・GameDistribution に対応しています。

| 広告の種類 | 出る場所 |
|---|---|
| リワード広告（見るかどうかはプレイヤーが選ぶ） | ワニマートの「ランダムな武器を1つ」「協賛金 $300」（3分に1回）／ゲームオーバー時の「その場で復活」 |
| インタースティシャル広告（区切りで自動） | ミッションクリア後、病院で目を覚ましたとき（3分以上あける） |

ほかに、プレイ中かどうかの通知（gameplayStart/Stop）、読み込み完了の通知、ミッションクリア時の happytime（CrazyGames）、広告中のゲーム停止と消音も入れてあります。

### アップロード用ファイルの作り方
```
python3 tools/build_portals.py --gd-game-id <GameDistributionのゲームID>
```
`dist/crazygames.zip`・`dist/poki.zip`・`dist/gamedistribution.zip` ができます。各サイトの開発者ページにアップロードしてください。

### ローカルで広告の流れを試す
`index.html?ads=test` で開くと、本物の広告の代わりに数秒のテスト表示が出ます。
